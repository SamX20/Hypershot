# HYPER SHOT 🎯

شوتر أونلاين في المتصفح — امسك العلم (Capture the Flag) مستوحى من لعبة Hypershot على روبلوكس.

## العب الآن
افتح رابط GitHub Pages الخاص بالمشروع على الكمبيوتر أو الموبايل.

## اللعب مع الأصدقاء
1. واحد يضغط **"أنشئ غرفة أونلاين"** فيطلع كود ورابط.
2. أرسل الرابط أو الكود لأصدقائك، وهم يضغطون **"انضم"**.
3. البوتات تكمّل الأماكن الفاضية.

## التحكم
| الكمبيوتر | الفعل |
|---|---|
| WASD / Space | حركة / قفز |
| الماوس | تصويب وإطلاق (زر يمين = منظار القناص) |
| 1 2 3 / العجلة | رشاش، شوزن، قناص |
| C | سلايد |
| Q | Upward Shift (دفعة لأعلى) |
| Shift | Tailwind (سرعة) |
| E | جرعة شفاء |
| Tab | النتائج |

على الموبايل: جويستيك للحركة، اسحب الشاشة للنظر، وأزرار للإطلاق والقدرات.

## القوانين
- أول فريق يجمع **10 أعلام** يفوز.
- حامل العلم صحته مضاعفة، لكن قدراته والسلايد معطلة.
- إذا مات حامل العلم يرجع العلم لقاعدته.
